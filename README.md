# 角落生物 · 快乐地生活在一起

一个手绘风格的角落生物（すみっコぐらし）粉丝页面，纯静态站点。

- 纯 HTML / CSS / SVG 单文件页面，适配手机屏幕
- 点击场景里的角色：弹跳、冒爱心、显示小台词
- 下方附 16 位角色的图鉴卡片
- 小游戏「穿过小山洞」：可单人或双人联机
  - 单人：选择任意角落生物，穿过不断出现的小山洞
  - 双人：两台设备都要先解锁页面并进入同一个房间；房主在另一位玩家在线后才能开始
  - 房间、角色和实时比分通过公共 MQTT 中继同步（需要网络）
- 小窝养成（全站共享）：
  - 玩小游戏获得金币
  - 在小角落商店购买食物
  - 喂食提升 16 位角色各自的全站好感度
  - 好感度由所有玩家共同累计；升级会为全站解锁新的互动动作：摸摸头、蹦蹦跳、转圈圈、爱心雨、抱抱
  - 主场景里的角色台词也会随全站好感度变化
  - 金币、食物库存和玩家自己的贡献通过浏览器匿名档案保存到云端（公共 MQTT 中继的 retained 消息），匿名 ID 存在本机
  - 全站好感度是 16 位角色各自一份，不是每位玩家各一份；公共中继不是正式数据库，消息可能被清理，清除浏览器数据也会丢失自己的匿名档案
