# 角落生物 · 快乐地生活在一起

一个手绘风格的角落生物（すみっコぐらし）粉丝页面，纯静态站点。

- 纯 HTML / CSS / SVG 单文件页面，适配手机屏幕
- 点击场景里的角色：弹跳、冒爱心、显示小台词
- 下方附 16 位角色的图鉴卡片
- 小游戏「穿过小山洞」：可单人或双人联机
  - 单人：选择任意角落生物，穿过不断出现的小山洞
  - 双人：两台设备都要先解锁页面并进入同一个房间；房主在另一位玩家在线后才能开始
  - 房间、角色和实时比分通过公共 MQTT 中继同步（需要网络）

在线访问：https://jackie-boy.github.io/sumikko-house/
